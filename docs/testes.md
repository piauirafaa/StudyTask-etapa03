# Testes do StudyTask

## Abertura do sistema
### Objetivo
Verificar se a página inicial do site é carregada corretamente.
### Procedimento
Abrir arquivo 'index.html' no navegador.
### Resultado esperado
A tela incial deve ser exibida corretamente.
### Resultado obtido
A tela foi exibida corretamente.
## Validação dos Campos
### Objetivo
Verificar se o sistema identifica campos vazios.
### Procedimento
Clicar no botão "Entrar" sem preencher e-mail e senha.
### Resultado Esperado
Aparecer a mensagem na tela: "Preencha todos os campos."
### Resultado Obtido
A mensagem foi apresentada.
## Preenchimento de Campos
### Objetivo

### Procedimento
Preencher os campos e clicar em "Entrar".
### Resultado esperado
Aparecer a mensagem na tela: "Login realizado!".
### Resultado Obtido
A mensagem foi apresentada.
